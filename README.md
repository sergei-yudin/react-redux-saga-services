# Список услуг — Redux Saga

Учебный проект к занятию «Redux Saga». Приложение показывает список услуг и страницу подробностей, загружая данные через саги.

## Запуск

Сначала запустите API:

```bash
cd backend
npm install
npm start
```

Во втором терминале запустите интерфейс:

```bash
npm install
npm run dev
```

Backend намеренно иногда отвечает ошибкой: в этом случае интерфейс покажет кнопку повторного запроса.

## Проверка качества

```bash
npm run format:check
npm run lint
npm run build
```

Опубликованная версия подставляет демонстрационные данные, поскольку локальный учебный backend недоступен из GitHub Pages. Redux Saga и состояния интерфейса используются в обоих режимах.
